# Diretriz de Integridade, Organização e Finalização Profissional

- Sempre no final de cada alteração, deixe o código-fonte sólido, organizado, devidas pastas em certos lugares, sem quebrar nada.
- O projeto tem que estar profissional em nível de produção.
- Ao final de cada atendimento ou entrega, o agente DEVE declarar explicitamente ao usuário que realizou esse procedimento e que o código está sólido, organizado e íntegro.
- Pergunte sempre ao final se o usuário deseja que o APK/Release seja gerado. Assim que o usuário confirmar, lance a nova Release com o APK imediatamente no GitHub Releases.
