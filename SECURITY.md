# Política de Segurança

## Reportar uma vulnerabilidade

Envie o relato de forma privada pela aba **Security** do repositório, usando
**Report a vulnerability** ou um GitHub Security Advisory. Não abra uma issue
pública para relatar uma vulnerabilidade não corrigida.

Inclua, se possível, a versão e o canal afetados, os passos para reproduzir, o
impacto observado e uma forma segura de entrar em contato. Evite anexar dados
pessoais, credenciais ou informações de usuários.

## Versões suportadas

São consideradas suportadas a release mais recente do canal mobile e a release
mais recente do canal Android TV. Versões anteriores podem não receber correções.

## Prazo de resposta

O objetivo é confirmar o recebimento em até cinco dias úteis e compartilhar uma
avaliação inicial assim que possível. O prazo pode variar conforme a gravidade e
a complexidade da análise; isso não constitui um SLA.
